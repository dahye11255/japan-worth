# 🇯🇵 JapanWorth

### 일본 쇼핑, 가격부터 면세까지 한눈에.

**일본 여행자를 위한 스마트 쇼핑 도우미**

[🌐 JapanWorth 바로가기](https://japan-worth.vercel.app)

## 1. 프로젝트 소개

JapanWorth는 일본 여행 중 상품을 구매할 때 한국과 일본의 가격을 비교하고, 환율과 면세 혜택, 여행 관련 정보를 함께 확인할 수 있도록 돕는 웹서비스입니다.

스마트폰으로 상품 바코드를 스캔하면 상품 정보를 조회하고, 한국 판매 가격을 검색할 수 있습니다. 일본 현지 판매 가격을 입력하면 환율을 적용한 예상 구매 비용을 비교하고 구매 예정 상품을 장바구니에 담을 수 있습니다.

특히 **2026년 11월 1일부터 시행되는 일본 소비세 면세 환급 방식 개편**을 고려하여, 여행자가 실제 구매 시점의 결제 금액과 추후 환급 가능 금액을 구분해 이해하도록 돕는 것을 중요한 서비스 목표로 설정했습니다.

## 2. 개발 배경 및 문제 정의

일본 여행 중 쇼핑할 때는 다음과 같은 어려움이 있습니다.

- **가격 비교의 어려움:** 일본 매장에서 본 상품이 한국보다 저렴한지 즉시 확인하기 어렵습니다.
- **상품 검색의 번거로움:** 일본어 상품명을 검색하거나 동일한 상품의 용량과 옵션을 구분해야 합니다.
- **환율과 세금 계산:** 엔화 가격을 원화로 환산하고 소비세 및 면세 조건을 고려해야 합니다.
- **지출 관리:** 여러 상품을 구매할 때 예상 총지출을 파악하기 어렵습니다.
- **여행 규정 확인:** 액체류와 주류는 항공기 반입 제한을 별도로 확인해야 합니다.

JapanWorth는 바코드 인식을 시작으로 상품 검색, 가격 비교, 면세 정보, 장바구니, 수하물 안내를 하나의 흐름으로 연결하고자 기획되었습니다.

## 3. 핵심 기획 배경: 2026년 11월 일본 면세 제도 개편

### 3.1 기존 제도와 개편 제도의 차이

일본은 **2026년 11월 1일 구매분부터 면세 제도를 환급 방식(Refund Method)으로 변경**합니다.

| 구분 | 2026년 10월 31일까지 | 2026년 11월 1일부터 |
|---|---|---|
| 매장 결제 | 면세 조건 충족 시 세전 가격 결제 | 소비세 포함 가격 우선 결제 |
| 출국 절차 | 기존 면세 절차 적용 | 세관의 물품 반출 확인 필요 |
| 세금 혜택 | 구매 시 소비세 면제 | 세관 확인 이후 소비세 상당액 환급 |
| 여행자가 고려할 금액 | 구매 시 결제액 | 최초 결제액과 예상 환급 후 부담액 |

환급 방식에서는 면세 대상 구매일로부터 **90일 이내**에 일본에서 출국하면서 세관 확인을 받아야 합니다.

공항이나 항구에서 반출 여부를 확인하지만, **실제 환급 지급은 면세점 또는 위탁 환급사업자가 처리**합니다. 따라서 반드시 공항에서 현금을 즉시 지급받는다는 의미는 아닙니다.

### 3.2 JapanWorth와의 연관성

이러한 변화로 여행자는 두 가지 금액을 구분해야 합니다.

1. **매장에서 당장 지불하는 소비세 포함 금액**
2. **출국 확인 후 환급 조건을 충족했을 때의 예상 최종 부담액**

JapanWorth는 소비세율과 상품별 면세 정보를 제공하여 이러한 구매 판단을 지원하는 방향으로 개발했습니다.

단, JapanWorth가 실제 세관 확인이나 환급금 지급을 수행하는 것은 아닙니다. 환급 여부는 면세점, 구매 조건, 출국 시 세관 확인 등에 따라 결정됩니다.

## 4. 실제 상품을 활용한 면세 환급 시뮬레이션

### 사례: &honey 딥모이스트 헤어오일 3.0 100mL

**실제 상품 정보**

- 상품명: &honey Deep Moist Hair Oil 3.0
- JAN: `4589546890796`
- 로프트 온라인 판매가: 세전 ¥1,450 / 세금 포함 ¥1,595
- 적용 소비세율: 10%

일본의 면세 최소 구매 기준인 **동일 면세점·동일 날짜 세전 합계 ¥5,000 이상**을 충족하는 상황을 가정합니다.

### 4개를 구매하는 경우

| 항목 | 금액 |
|---|---:|
| 상품 1개 세전 가격 | ¥1,450 |
| 상품 1개 세금 포함 가격 | ¥1,595 |
| 세금 포함 결제 금액 (4개) | ¥6,380 |
| 세전 상품 금액 합계 | ¥5,800 |
| 예상 소비세 환급액 | ¥580 |
| 환급 후 최종 예상 부담액 | **¥5,800** |

계산식:

- 최초 결제 금액 = ¥1,595 × 4 = **¥6,380**
- 예상 환급액 = ¥6,380 × 10 ÷ 110 = **¥580**
- 환급 후 부담액 = ¥6,380 − ¥580 = **¥5,800**

반대로 같은 상품을 3개만 구매한다면 세전 합계가 ¥4,350으로 최소 구매 기준에 미달합니다.

이 사례는 **실제 판매 상품과 확인 가능한 판매 가격을 사용한 계산 예시**입니다. 2026년 11월 이후 발생한 실제 환급 거래는 아니며, 해당 면세점의 실제 자격·적격 구매자·상품 반출·세관 확인·환급 수수료 등을 충족한다고 가정한 시뮬레이션입니다.

이처럼 단순한 상품 가격 비교뿐 아니라 **구매 수량과 면세 조건에 따른 예상 비용 차이**도 쇼핑 의사결정에 중요한 요소라는 점에 주목했습니다.

## 5. 주요 기능

### 5.1 바코드 스캔

- 스마트폰 카메라로 JAN/EAN 바코드 인식
- 바코드 번호 직접 입력 지원
- 바코드에 연결된 상품명, 브랜드, 이미지 등 표시

**기술:** `@zxing/browser`

### 5.2 로컬 상품 DB 및 외부 상품 자동 조회

상품 조회는 두 단계로 작동합니다.

**① 로컬 상품 조회**

`products.ts`에 등록된 JAN이 있으면 저장된 상품 정보를 우선 표시합니다.

**② 외부 상품 조회**

로컬 데이터에 없는 JAN이라면 `/api/product`에서 외부 상품정보를 검색합니다.

- SerpApi를 이용한 일본 상품 검색
- Open Facts 및 UPCitemdb 보조 조회
- JAN 일치 여부 확인
- Google Cloud Translation API를 통한 한국어 상품명 변환
- 한국 가격 검색에 적합한 검색어 생성

외부에서 상품을 찾지 못한 경우 직접 상품명을 입력하는 대체 경로도 마련했습니다.

### 5.3 한일 가격 비교

- 한국 Google Shopping 기반 상품 검색
- 일본 현지 가격 직접 입력
- 엔/원 환율 적용
- 예상 가격 차이 및 절약 금액 표시
- 네이버 쇼핑 및 쿠팡 관련 외부 검색 연결

일본 현지 가격은 사용자가 확인한 판매가를 입력하는 방식이며, 한국 검색 결과는 판매처와 상품 옵션에 따라 달라질 수 있습니다.

### 5.4 환율 적용

Frankfurter API를 이용하여 일본 엔화를 한국 원화로 환산합니다.

API 조회에 실패했을 경우를 위한 대체 환율값도 설정했습니다.

실제 카드 결제 환율과 수수료는 차이가 있을 수 있으므로 예상 금액으로 안내합니다.

### 5.5 소비세 및 면세 정보

상품별로 다음 데이터를 관리합니다.

- 소비세율 `taxRate`
- 면세 대상 가능 여부 `taxFreeEligible`
- 상품 분류 `taxCategory`

일반 소비세율 10%와 일부 식품에 적용되는 경감세율 8%를 구분합니다.

실제 면세 및 환급 여부는 매장 자격, 구매 금액, 구매일, 여행자 자격과 반출 확인 등에 따라 달라집니다.

### 5.6 장바구니 관리

- 비교한 상품 장바구니 추가
- 동일 상품 수량 관리
- 예상 구매 비용과 절약 금액 확인
- 브라우저 `localStorage`에 구매 예정 정보 저장

### 5.7 항공기 수하물 안내

상품의 액체 용량과 알코올 도수 정보를 활용하여 일반적인 국제선 항공기 반입 제한을 안내합니다.

**예시**

- 산토리 -196 거봉 500mL: 일반적인 기내 액체류 제한 대상, 위탁수하물 권장
- 스피리터스 96도 500mL: 기내·위탁수하물 모두 운송 불가

보안검색 이후 구매한 면세품이나 항공사·경유지에 따른 예외가 있으므로 참고 정보로 제공합니다.

## 6. 서비스 이용 과정

1. **바코드 스캔:** 상품 바코드를 카메라로 인식하거나 직접 입력합니다.
2. **상품 정보 조회:** 로컬 데이터 또는 외부 API에서 상품을 찾습니다.
3. **한국 가격 확인:** 쇼핑 검색 결과에서 관련 상품을 확인합니다.
4. **일본 가격 입력:** 일본 매장에서 확인한 가격을 입력합니다.
5. **비교 결과 확인:** 환율을 반영한 예상 금액과 가격 차이를 확인합니다.
6. **구매 정보 관리:** 장바구니, 면세 정보, 수하물 안내를 참고합니다.

## 8. 개발 과정에서 마주한 문제와 개선

### 8.1 JAN 검색의 정확도 문제

초기 개발 과정에서 JAN으로 일본 상품을 검색할 경우 바코드와 관계없는 상품이 반환되거나 비슷한 제품이 선택되는 문제가 발생했습니다.

특히 다음과 같은 오류를 확인했습니다.

- 헤어오일 본품 대신 리필 상품 검색
- 헤어오일 대신 샴푸·트리트먼트 세트 이미지 연결
- 단품 립밤 대신 묶음 상품 검색
- 립밤과 관계없는 상품이 검색되는 현상

이를 개선하기 위해 JAN 확인, 상품명 정리, 본품·리필 구분, 상품 종류별 이미지 매칭 조건을 보완했습니다.

### 8.2 Yahoo! JAPAN Shopping API 연동의 한계

일본 현지의 상품정보 및 판매가격을 더욱 정확하게 가져오기 위해 **Yahoo! JAPAN Shopping API 연동을 고려했지만, 프로젝트에서 실제 연동을 완료하지 못했습니다.**

Yahoo! JAPAN은 현재도 JAN 코드 검색을 지원하는 상품 검색 API v3를 제공하고 있습니다. 그러나 프로젝트 개발 과정에서는 이를 안정적으로 활용하는 데까지 연결하지 못했습니다.

그 결과 일본 판매 가격의 완전 자동 조회보다는 **사용자가 일본 현지 가격을 직접 입력하는 방식**을 채택했습니다.

향후에는 Yahoo! JAPAN Shopping API의 인증 및 연동 조건을 재검토하고, 일본 현지 판매가격을 자동으로 수집하여 비교 정확도를 높이고자 합니다.

### 8.3 유료 API 및 데이터 확보의 제약

상품 검색 및 가격 비교의 완성도를 높이려면 정확한 상품 식별 정보, 일본 현지 가격, 한국 판매 가격, 상품 옵션별 데이터가 충분히 확보되어야 합니다.

그러나 프로젝트 개발 과정에서는 상용 상품 DB 및 고급 쇼핑 API의 비용과 이용 조건을 고려해야 했습니다.

이러한 제약으로 인해 다음 기능은 충분히 고도화하지 못했습니다.

- 일본 주요 쇼핑몰의 상품 가격 자동 수집 범위 확대
- 동일 JAN을 기준으로 한 양국 상품 가격의 정확한 매칭
- 상품 가격의 지속적인 갱신
- 용량, 리필 여부, 묶음 구성 등 세부 옵션 구분
- 안정적인 대량 상품 검색

이를 보완하기 위해 로컬 상품 데이터와 외부 API를 혼합하는 구조를 사용했습니다.

### 8.4 팀 협업 및 데이터 관리

팀원별로 상품 정보와 이미지를 추가하는 과정에서 중복 JAN, 이미지 경로 및 상품 분류를 점검했습니다.

GitHub 브랜치와 Pull Request를 이용하여 변경사항을 병합하고, 로컬 개발 및 Vercel 배포 환경을 관리했습니다.

## 9. 프로젝트 한계

- 외부 상품 검색 결과의 정확도와 범위가 API에 따라 달라질 수 있습니다.
- Yahoo! JAPAN Shopping API를 통한 일본 판매가 자동 연동은 완료하지 못했습니다.
- 상용 데이터 및 API 이용 범위의 제약으로 광범위한 실시간 상품 정보를 확보하지 못했습니다.
- 일본 가격은 사용자가 직접 입력해야 하며, 한국 가격은 쇼핑 검색 결과에 의존합니다.
- 상품의 세금 정보는 참고용이며 실제 면세 자격을 보장하지 않습니다.
- 2026년 11월 환급 절차를 안내하는 것은 가능하지만, 실제 세관 시스템이나 환급 사업자와 직접 연동한 서비스는 아닙니다.
- 항공기 수하물 안내는 일반적인 기준에 따른 참고 정보입니다.
